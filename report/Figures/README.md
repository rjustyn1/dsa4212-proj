# Figure asset policy

Place every report figure and its final exported asset in this directory.

- Use stable, ordered names such as `fig_01_validation_nll_difference.pdf`.
- Prefer vector PDF for plots; use PNG only when raster imagery is necessary.
- Keep captions and cross-references in the relevant `sections/*.tex` file.
- Record each figure's source metrics and generating command in `TODO.md`
  before treating it as publication-ready.
- Do not place LaTeX build artefacts here.
